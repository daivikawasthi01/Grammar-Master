# Reports

Everything in this directory was produced **before** the current `/api/check` route, the `check-v3` prompt and the corrected GLEU/F0.5 scoring. The numbers describe retired code and use per-sentence averaging with no no-op baseline, so they are not comparable with new runs and must not be quoted.

New runs write `benchmark_latest.{md,json}` and `rule_eval_latest.{md,json}` here.
